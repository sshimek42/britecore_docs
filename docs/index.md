# britecore_docs

Welcome to the consolidated BriteCore documentation hub.

This project is intended to unify documentation across several local repositories and tools:

- `britecore_mcp` — MCP server, report tools, and report-table documentation
- `britecore_sdk` — Python SDK for the BriteCore API
- `PolicyReporting` — cross-source reporting service layer
- `britecore-csv-loader` — raw CSV relationship discovery and extraction tooling

## What this project should become

A shared docs layer for:

- architecture across tools
- data flow and integration patterns
- logical-layer reporting guidance
- cross-project setup and usage guides
- curated references back to source repos

## Current state

This scaffold includes:

- a source registry
- a project map
- ingestion workflow notes
- a reporting/logical-layer overview
- project summary pages for each local source repo

## Recommended workflow

1. Keep detailed implementation docs in the source repos.
2. Use `britecore_docs` for cross-project overviews and curated guides.
3. Link back to source files when the canonical implementation details live elsewhere.
4. Promote high-value cross-repo patterns into this project once they stabilize.
